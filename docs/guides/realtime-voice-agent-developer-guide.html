00 / AUTHORITY

先知道什么才是最终事实

本 HTML 是非规范性图解。发生冲突时，wire 以 protocol/ 的 registry、schema 和 fixtures 为准；架构以 Product ADR 为准；测试结果只对记录的 source/artifact identity 有效。

不要从页面示例复制新的手写协议常量。Server 与 Firmware consumer 必须由同一 machine-readable contract 校验。
01 / SYSTEM

一对一媒体单跳，控制面可水平扩展

02 / SERVER

Binding 可替换，canonical runtime 不懂设备方言

Director owns

  • Worker registry、capacity、drain
  • route lease 与 fencing token
  • 短期、单次 connect grant
  • 不读取音频、不创建 AgentSession

Worker owns

  • /rva/v1/voice control 与唯一 media owner
  • codec、AgentSession、provider stream
  • playback generation 与 teardown
  • 服务端唯一 interruption 裁决
03 / FIRMWARE

ESP-IDF 是底座，不是另一个语音应用

04 / PROTOCOL

RVA control：少事件，但不删除必要语义

session.open

设备声明版本、identity、profiles、audio parameters、capabilities 和 limits。

session.opened

Worker commit 唯一 profile，返回 epoch、heartbeat/limits；UDP 时附带短期 grant。

transcript.*

流式 ASR delta/final；文本只属于当前 session/turn。

response.*

响应开始、文本、结束和精确 cancel；所有输出绑定 playback generation。

session.close

携带稳定 close reason；断线后 fresh bootstrap，不恢复旧 key 或 generation。

wss-opus/1

WSS 同时承载 JSON control 与 typed binary Opus。实现简单，但必须限制 queue、message size 和 media age，防止 TCP HOL 扩散。

udp-opus-gcm/1

WSS 管理生命周期；UDP 只传 AEAD Opus。认证失败不推进 sequence、不进入 decoder；迟到包按 deadline 丢弃。

05 / LIFECYCLE

打断正确性来自 owner 与 generation

不变量失败时必须发生
一个 session 一个 control owner重复 open 或 split-brain 明确拒绝
playback generation 单调增加旧 callback、queue、datagram 不能进入 DAC
cancel target 精确未知或 stale target 不猜测相近 response
close 幂等且有界先 revoke admission，再停止 task/socket，最后释放资源
fresh reconnect旧 epoch、key、grant、sequence 全部失效
06 / WORKFLOW

开发顺序围绕可运行纵向闭环

# Server（Linux/container）
uv sync --directory server --locked --all-packages --dev
uv run session-director
uv run realtime-worker

# Firmware
cd firmware/apps/voice_terminal
idf.py set-target esp32s3
idf.py build
idf.py size

# 只有设备与端口已确认并获授权后
idf.py -p "$RVA_ESPPORT" flash monitor
候选构建成功不等于最终镜像或设备通过。生命周期修复后必须 fresh rebuild；没有当前 artifact 的串口、hash、端云 trace 或声学证据时，对应状态必须是 not_run。
07 / QUALITY

把快循环和发布证据分开

证据层必须证明不能替代

measured固定环境的 soak、延迟、queue 与弱网样本可复核其他硬件和部署环境
当前候选已覆盖 repository、Server、Desktop Reference、Redis integration、WSS/UDP host E2E、native host contracts 与 ESP-IDF build/size 门禁，并已有公网 Linux 和 ESP32-S3 HIL 证据。精确 commit、CI run、artifact digest 和仍待执行的门禁统一由 Release readiness 维护；本文不复制易过期的候选身份。

当前已验证

ESP32-S3 已完成 udp-opus-gcm/1 双向 Opus 闭环；authenticated probe、source pinning、完整 playback fact、normal close 与 exact release 均有绑定历史 artifact 的证据。Desktop real-provider canary 同时覆盖 ASR、LLM、TTS、完整 playback 和资源释放。

当前仍未完成

历史 WSS artifact虽完成播放，随后发生 freshness overload；修复源码 host 回归已通过，最终 artifact 的 WSS HIL 仍为 not_run。固定弱网矩阵、绑定最终 artifact 的长时间 soak、延迟分位数和跨环境声学指标仍为 not_run/incomplete。

08 / COMPATIBILITY

已退役兼容面不进入当前产品

Current production 设备先经 Director bootstrap 获取 worker-bound grant，再连接选定 Worker 的 /rva/v1/voice；设备 wire 仅为 rva/1 与 wss-opus/1 / udp-opus-gcm/1。

当前产品边界

  • ESP-IDF native application
  • Director bootstrap → worker-bound grant → /rva/v1/voice
  • rva/1 + wss-opus/1 / udp-opus-gcm/1
  • Director + Worker + provider adapters

不属于当前兼容面

  • 绕过 Director 的生产接入
  • 未注册的 control/media profile
  • 未注册的 route、字段或消息
  • 不参与 current release gate
Lab token 鉴权仍仅用于 development 的单进程/隔离调试，并继续使用 rva/1；production 必须禁用。单进程调试不再需要或设备 enrollment/rotation 替代 shared credential 后，复查并删除该配置、测试和运维面。
